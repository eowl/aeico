Implementation Comparison

innerHTML Method (Baseline)

Uses shadowRoot.innerHTML = '...' to render content as a string template. Simple and direct but recreates the entire DOM tree on every render.

Preview

Code Implementation

protected render() {
  if (!this.shadowRoot) return

  const type = this.type || 'button'

  this.shadowRoot.innerHTML = `
    <button 
      class="btn" 
      type="${type}"
      ${this.disabled ? 'disabled' : ''}
      part="button"
    >
      <slot></slot>
    </button>
  `

  this.buttonElement = this.shadowRoot.querySelector('button')
}

draw() Method

Uses imperative DOM APIs with smart diffing algorithm. Reuses existing DOM nodes, updates only changed properties, and preserves element references.

Preview

Code Implementation

protected render() {
  this.draw(() => {
    const { button, slot } = this.tags

    button({
      className: 'btn',
      type: this.type || 'button',
      disabled: this.disabled,
      part: 'button',
      key: 'main-button'
    }, () => {
      slot()
    })
  })

  // Query button element if needed
  if (!this.buttonElement) {
    this.buttonElement = this.shadowRoot!.querySelector('button')
  }
}
